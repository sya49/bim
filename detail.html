Hello World! — Halaman HTML Pertama

Teori

HTML (HyperText Markup Language) adalah bahasa markup untuk membuat halaman web. Setiap dokumen HTML memiliki struktur wajib:
<!DOCTYPE html>, <html>, <head>, dan <body>.
Tag <head> berisi metadata seperti judul halaman, sedangkan <body> berisi konten yang ditampilkan ke pengguna.
