Input & Output — Program Sapaan

Teori

Python menggunakan print() untuk menampilkan output dan input() untuk menerima input dari pengguna. Python tidak membutuhkan titik koma di akhir baris. Indentasi (spasi) sangat penting — Python menggunakan indentasi untuk mendefinisikan blok kode, bukan tanda kurung kurawal.
