Teori

Java adalah bahasa pemrograman yang berjalan di JVM (Java Virtual Machine). Setiap program Java harus memiliki method main. Java adalah bahasa yang strongly-typed — setiap variabel harus dideklarasikan dengan tipenya. Tipe primitif: int, double, boolean, char. String adalah tipe referensi untuk teks.
